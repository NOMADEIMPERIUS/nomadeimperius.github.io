# Nômade Impérius

Site oficial da agência de marketing Nômade Impérius.

**Endereço:** https://nomadeimperius.github.io/

Site estático em HTML, CSS e JavaScript, com identidade preta e dourada, imagens, serviços de marketing e contato pelo WhatsApp.

## Publicação

GitHub Pages: branch `main`, pasta `/ (root)`. O arquivo `.nojekyll` mantém a publicação estática.

## Contato

O número comercial confirmado está em `config.js`: `5531997046462`. Os botões abrem o WhatsApp com uma mensagem pronta. O envio da mensagem depende da ação do visitante.

O briefing é preparado no navegador e pode ser revisado, copiado, baixado ou levado para uma conversa. Não há armazenamento permanente de leads no site.

As cenas de serviços são ilustrativas. A licença das fontes está em `font-license.txt`.
